# Legacy v1 Documentation Archive

This folder is where all legacy v1 documentation should be copied from the old project.

## Purpose

- **Reference**: Keep old documentation for historical context
- **Migration**: Extract useful patterns and lessons learned
- **Isolation**: Prevent legacy mess from leaking into v2 architecture

## Usage Guidelines

1. **Copy** all old documentation here first
2. **Review** and extract valuable insights
3. **Distill** key information into proper v2 docs
4. **Reference** but don't copy-paste old solutions

## What to Archive

- Old setup guides
- Architecture decisions (good and bad)
- Known issues and workarounds
- Performance bottlenecks discovered
- Import scripts and data processing notes
- API documentation
- Database schema evolution

## What NOT to Copy to v2

- One-off hacks and workarounds
- Deprecated dependency configurations
- Overly complex solutions that can be simplified
- Technical debt and band-aid fixes

The goal is to learn from v1 while building v2 cleanly.
